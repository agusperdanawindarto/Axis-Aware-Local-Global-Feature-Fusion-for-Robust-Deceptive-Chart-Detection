# Dataset source

Harmful Visual Plots Dataset (HVPD), Deceptive Visualization Classification Subset.
https://huggingface.co/datasets/WieszczUrsynowa/HVPD-HarmfulVisualPlotsDataset

The 24,480-image synthetic experiment excludes 187 separately named web-chart examples in the 24,667-image downloaded DVCS.zip archive.
Verified split from Kaggle: train 19544, validation 2465, test 2471, with numeric-series and exact-SHA256-disjoint grouping.

The actual images are excluded from this Git repository. Save the Kaggle split_manifest.csv in local_artifacts and do not replace it without an audit.
